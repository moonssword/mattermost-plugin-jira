# Security policy

## Supported versions

Only the latest release of this fork gets security fixes. Upstream security fixes of the 4.8 line are merged as they are released.

## Reporting a vulnerability

Please do not open a public issue.

- **A vulnerability in this fork** (the right-hand sidebar and the code under `server/rhs_*`, `webapp/src/components/rhs`): report it privately through [GitHub security advisories](https://github.com/moonssword/mattermost-plugin-jira/security/advisories/new).
- **A vulnerability that also exists in the official plugin**: report it to Mattermost as described in their [responsible disclosure policy](https://mattermost.com/security-vulnerability-report/).

Include the version, the steps to reproduce and the impact. Please give us a reasonable time to fix the issue before disclosing it.
